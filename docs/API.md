# API сервиса учета музейных выставок

Базовый адрес: http://127.0.0.1:8000/api/ . Ответы — JSON в UTF-8.
Чтение открыто. Изменение — только редактору после входа через /accounts/login/.

| Метод и путь | Назначение |
| --- | --- |
| GET /api/exhibitions/ | Каталог: q, limit (1–100), offset (0–1000000) |
| POST /api/exhibitions/ | Создать выставку |
| GET /api/exhibitions/{id}/ | Карточка с залом и куратором |
| PATCH /api/exhibitions/{id}/ | Отменить: is_cancelled=true |
| GET /api/halls/ | Получить залы |
| POST /api/halls/ | Добавить зал |
| GET /api/curators/ | Получить кураторов |
| POST /api/curators/ | Добавить куратора |

Пример создания выставки:

```json
{
  "title": "Графика города",
  "hall_id": 1,
  "curator_id": 1,
  "start_date": "2027-03-01",
  "end_date": "2027-03-10",
  "description": "Выставка городской графики"
}
```

Ответ: 201, `{"id": 6}` (ID — пример), Location с адресом API-карточки.
Описание необязательно. Зал и куратор должны существовать; даты — не пересекаться
с другой неотмененной выставкой в этом зале.

Зал: name, capacity, необязательные hall_type и description.
Куратор: name, email. Отмена: строго `{"is_cancelled": true}`.
Удаление, восстановление отмены и произвольное редактирование не реализованы.

POST/PATCH требуют Content-Type: application/json, cookie сессии и X-CSRFToken.
Токен берется из скрытого поля формы, созданного тегом csrf_token:

```javascript
await fetch('/api/exhibitions/', {
  method: 'POST',
  credentials: 'same-origin',
  headers: {
    'Content-Type': 'application/json',
    'X-CSRFToken': form.querySelector('[name=csrfmiddlewaretoken]').value
  },
  body: JSON.stringify(data)
});
```

Этот код применяется формами /workspace/ и кнопкой отмены в карточке.
После успеха клиент открывает карточку или обновляет статус; при ошибке
показывает текст сообщения через textContent, без вставки пользовательского HTML.

| Код | Значение |
| --- | --- |
| 200 / 201 | Успех / создано |
| 400 | Некорректные поля, JSON или параметры |
| 401 | Нет сессии для изменения данных |
| 403 | Недостаточно прав или отказ CSRF |
| 404 | Запись не найдена |
| 405 | Неподдерживаемый метод |
| 409 | Пересечение дат или нарушение связей |
| 503 | База временно недоступна |

Ошибки обычно имеют вид `{"error": "сообщение"}`. Отказ CSRF может вернуть HTML;
клиент обрабатывает и этот случай. Вход ограничен восемью неудачными попытками
с одного IP за пять минут (429). Ограничение действует в одном локальном процессе.
