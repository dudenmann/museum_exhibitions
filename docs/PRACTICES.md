# Как понять и показать практики

Подготовка создала классы Hall, Curator, Exhibition, JSON, консольные сценарии
и тесты. Это подготовка сейчас, а не заявление о сдаче ПР1–ПР3.

## ПР5

Тег PR5, коммит a2fe2e7. Данные из JSON.
Браузер запрашивает /halls/1/, корневой urls.py передает запрос halls,
конвертер int выделяет ID 1, view получает объект и возвращает HTML в HttpResponse.
Несуществующий ID вызывает Http404; неизвестный адрес не совпадает с маршрутами.

Созданы три приложения, URL двух уровней, главная, списки и карточки,
поиск свободных залов, навигация, экранирование HTML и собственный CSS.
Bootstrap не подключался: используется собственный CSS, допустимый чек-листом PDF.
Покажи `git show PR5:halls/views.py` и объясни 200, 404 и цепочку URL → view → ответ.

## ПР6

Тег PR6, коммит 381dc6d. JSON сохранен; ORM отсутствует.
View вызывает render и передает context. base.html задает каркас, extends
наследует его, block заменяет части, include подключает меню и карточки.
for выводит коллекцию, empty — пустое состояние, if — статус отмены.
Фильтры форматируют даты, подставляют описание и сокращают длинный текст.
Именованные URL используют app_name. CSS, SVG и JS подключаются через static.
Старая page больше не вызывается представлениями.

Покажи базовый шаблон, include карточки, render и static. Найди цикл и условие.
Объясни, почему проверка занятости зала находится в Python, а не в шаблоне.

## ПР7

Тег PR7, коммит c609c0e. Данные сайта — SQLite.
Путь: SQLite → SQL → sqlite3.Row → context → шаблон. Даты преобразуются в date.
Залы и кураторы связаны с выставками внешними ключами. Импорт использует
executemany и транзакцию; повторный импорт не затирает записи.

| Запросы | Что показывают | Страница |
| --- | --- | --- |
| halls_list, curators_list | 2 списка | Залы, кураторы |
| halls_capacity, available_halls | 2 WHERE, подзапрос | Вместимость, свободные залы |
| exhibition_catalog, exhibition_detail | 2 JOIN | Каталог, карточка |
| hall_totals, exhibition_totals | 2 агрегатных запроса | Обзор, статистика |
| exhibitions_by_hall, exhibitions_by_curator | 2 GROUP BY, HAVING | Статистика |
| exhibition_search | Поиск LIKE | Каталог |
| hall_detail | Поиск по ID | Карточка зала |
| missing_descriptions | NULL и пустые значения | Статистика |

Все 13 запросов используются веб-приложением. Запусти `python -m db.check_queries`.
WHERE отбирает записи; HAVING — группы после подсчета.
На demo-наборе с 2026-11-05 по 2026-11-10 свободен Исторический зал:
отмененная выставка не занимает его. Покажи этот поиск и статистику.

## Дополнения Word

Есть API и fetch, вход и роли, хеширование паролей, CSRF, параметризованный SQL,
экранирование HTML, транзакции и индексы. Сводка кэшируется на 30 секунд;
при изменении через API кэш сбрасывается. Локальное развертывание:
Waitress, WhiteNoise, DEBUG=False, журнал и /health/.
Выполнены модульные, интеграционные и небольшая нагрузочная проверки.

Системный пользователь, брандмауэр, публичный сервер, TLS, автозапуск и внешнее
наблюдение не настраивались: реализован согласованный локальный вариант.
Это не заявление о выполнении всех возможных инфраструктурных действий из Word.

файлы и URL, проверки, коммит и вывод. Не отмечай выполненным курс, который
не проходился. Для титульного листа нужны подтвержденные ФИО, группа и вариант.

браузерная проверка не была разрешена. Их можно сделать вручную.
